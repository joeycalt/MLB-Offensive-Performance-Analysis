# MLB Offensive Performance: Historical Player Archetype Dashboard 

## Project Summary
####
This project analyzes a historical dataset of over 10,000 Major League Baseball hitting records to evaluate how different player styles generate value on the field. Using Microsoft Excel, I transformed a massive, flat data table into an interactive performance dashboard. By leveraging advanced Pivot Tables, structural chart layering, and internal relative calculations, this dashboard moves beyond basic volume metrics to isolate the unique production profiles of Balanced, Power, and Speed hitters.

## Technical Features & Dashboard Architecture 
####
* **Dynamic Data Aggregation:**
    Summarized thousands of rows of historical player data using robust Pivot Tables to isolate key offensive metrics (Hits, Home Runs, RBIs, Stolen Bases).
* **Advanced Relative Calculations:**
    Used built-in Pivot Table data layouts (`% of Row` and `% of Column`) to build custom calculations that evaluate player archetypes as individual 100% profiles.
* **100% Stacked Visual Layering:**
    Overcame Excel's standard charting limitations to construct a clean, uniform 100% Stacked Column chart that illustrates internal behavioral differences without altering the core database structure.
* **Executive Presentation Layer:**
    Designed a human-readable, professional dashboard tab stripped of gridlines and raw clutter, optimized for rapid executive decision-making.

## The dashboard delivers three critical analytical viewpoints to a stakeholder: 
###
1. **Total Volume Limits:** Highlights the raw, absolute statistical footprint across all player classifications.
2. **Performance Breakdown by Archetype (100% Stack):** Compares player profiles relative to themselves. This proves that while "Balanced" players hold the highest raw volume, "Power" hitters allocate a vastly higher percentage of their internal production toward run-generation (RBIs/HRs).
3. **Metric Market Share:** Evaluates who owns the largest slice of individual performance categories across the entire league.
